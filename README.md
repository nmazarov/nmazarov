## 👨‍💻 Обо мне

Я DevOps-инженер с фокусом на **Security Hardening** и глубокую автоматизацию. Верю, что инфраструктура должна быть описана кодом (IaC), а безопасность — интегрирована в каждый этап жизненного цикла разработки.

* 🛡️ **DevSecOps:** Внедряю Shift-Left Security (Trivy, SonarQube) и защищенные туннели (WireGuard, VLESS).
* ⚙️ **Automation:** Пишу сложные сценарии на Ansible и Bash, которые экономят сотни часов ручного труда.
* 🔭 **Сейчас:** Углубляюсь в архитектуру Kubernetes и высоконагруженные системы на базе Kafka.
